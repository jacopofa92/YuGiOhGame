# Documentazione del progetto

La radice del repository conserva soltanto i documenti necessari per orientarsi
subito nel progetto:

- `AGENTS.md`: regole operative per gli agenti;
- `README.md`: presentazione e avvio rapido;
- `PROJECT_MAP.md`: mappa tecnica aggiornata;
- `PUBBLICAZIONE.md`: procedura di pubblicazione;
- `CLAUDE.md`: diario tecnico storico.

La documentazione di dettaglio è divisa per argomento:

- `architecture/`: guide architetturali e di riutilizzo;
- `audits/`: analisi interpretate di carte, IA, duellanti e difficoltà;
- `cards/`: note sul catalogo carte;
- `economy/`: acquisizione carte e bilanciamento del farming;
- `planning/`: lavoro aperto, TODO e archivio dei bug.

I dati grezzi prodotti dagli strumenti di analisi sono invece in `reports/`.
